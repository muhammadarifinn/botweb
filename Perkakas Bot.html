Bot Google Form

Baca isi sebuah Google Form, lihat pertanyaannya, lalu buat data dummy yang cocok untuk tiap pertanyaan.

Halaman web tidak boleh mengirim data ke situs lain, jadi pengiriman ke Google Form dijalankan lewat skrip Python di komputer Anda. Di sini Anda membaca form, melihat data contoh, menyalin CSV, dan menyalin perintah untuk skripnya.

1. Tempel kode sumber form

  1. Buka form Anda di browser (form harus publik, tanpa wajib login).
  2. Tekan Ctrl+U untuk membuka kode sumber halaman.
  3. Tekan Ctrl+A, lalu Ctrl+C, dan tempel di bawah ini.
  4. Download file python untuk menajlankan dummy nya di sini.

Ini contoh form tiruan. Tempel kode sumber form Anda di atas untuk menggantinya.
NoTipeWajibPertanyaanOpsi

2. Buat data dummy

Isian teks ditebak dari judul pertanyaan (nama, nomor HP, email, alamat, jumlah). Pilihan diambil dari opsi yang ada di form.

Atur jawaban sendiri (opsional)

Satu objek JSON. Kuncinya sebagian kata dari judul pertanyaan. Format sama dengan aturan.json milik skrip Python.

3. Kirim ke form dari komputer Anda

Jalankan perintah ini di terminal, di folder tempat bot_form_universal.py berada. Uji dulu dengan -n 3.
